# 视频录音转文字 video2srt · 隐私政策

最后更新：2026-11-06

本扩展不收集、不上报任何个人数据，不包含统计、遥测或广告代码。以下是本地数据的完整去向说明。

## 我们收集什么数据

**不收集任何个人身份数据、浏览历史或用户行为数据。**

扩展在本地处理以下内容：

- **转写 API 配置**（API 地址、API Key、模型名、语言、码率、分段时长、倍速与跳广告开关）：只保存在你浏览器的本地存储（`chrome.storage.local`）中，用于本扩展的设置页与录制流程。
- **当前标签页的音频**：仅在你主动点击「开始」录制后，捕获当前标签页正在播放的声音，用于生成 MP3 与字幕。
- **当前页面的视频标题与播放进度**：仅在开始录制时读取一次，用于本地文件命名和字幕时间轴对齐；**不会**发送给任何服务器（转写请求只包含音频数据与模型参数，不含标题等页面信息）。

## 数据如何存储与传输

- 所有配置只存本机浏览器，不使用任何云同步。
- 录音文件（MP3/SRT）直接保存到你电脑的下载目录，不经任何中转服务器。
- **唯一的对外传输**：如果你自行填写了转写 API 地址，录音音频在你点击「结束」后会被发送到**你自己配置的那个服务地址**用于生成字幕；未配置转写 API 时，音频完全不离本机（只保存 MP3）。开发者无法接触你的音频与 API Key。

## 第三方服务

扩展自身不内置、不调用任何第三方服务。转写功能由你自行选择服务商并填写地址（例如硅基流动或自建网关），该服务的隐私政策适用于你发送给它的音频数据。

## 数据共享

不与任何第三方共享数据，不出售数据，不用于任何与扩展功能无关的目的。

## 数据保留与删除

- 配置可随时在扩展设置页查看、修改或清空。
- 录音与字幕文件保存在你自己的下载目录，由你自行管理、删除。
- 卸载扩展即清空其全部本地存储数据。

## 政策变更

如功能变化涉及数据处理方式，本政策会同步更新。
